# AGENTS.md — read this first

This repository is a university lab project (ITUE301 Advanced Web Development Frameworks).
All instructions for finishing Practicals 6–13 live in `agent-guide/`.

**Before doing anything:**
1. Read `agent-guide/README.md` (the entry point and the rules).
2. Read `agent-guide/00-project-context.md` (structure, stack, API contract, env vars).
3. Read `agent-guide/STATUS.md` to see which practical is next.
4. Open only the practical file you are working on (`agent-guide/06-...md`, `07-...md`, etc.).

Do not wait for the user to re-explain anything. If the guide answers a question, follow the guide.
Never modify `practical_1` … `practical-7` folders (they are read-only archives).
